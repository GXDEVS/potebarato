Como funciona

1

Dados públicos

Crawlers visitam páginas públicas de lojas de suplementos e extraem dados estruturados via JSON-LD (Schema.org) indexados pelo Google.

2

Atualização automática

A cada 6 horas o scraper roda em processo isolado, atualizando preços, estoque e imagens via upsert no banco PostgreSQL.

3

API REST simples

Consulte preços, filtre por marca e compare produtos com uma única chamada. Documentação completa disponível com OpenAPI.

Sobre o projeto

Projeto educacional

O potebarato foi criado com fins exclusivamente educacionais como um estudo de web scraping, APIs REST e comparação de preços. Todos os dados exibidos são públicos, coletados diretamente das páginas das lojas indexadas pelo Google. Este projeto não possui fins comerciais e não armazena dados pessoais de terceiros.
